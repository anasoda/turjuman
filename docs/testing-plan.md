## المرحلة 14ب — دور مدير المرحلة (10 دقائق)

> منشور ✅. أنشئ الحساب أولاً كمدير المركز — لا يوجد حساب مدير مرحلة على الإنتاج بعد.

### إنشاء الحساب
- [ ] الكادر ← «إضافة حساب» ← نوع الحساب **«مدير مرحلة»** ← تظهر مربّعات «المراحل التي يديرها».
- [ ] اختر **مرحلة واحدة فقط** (مثلاً «ابتدائي») ← أكمل البيانات ← حفظ.
- [ ] يظهر في تبويب **«مديرو المراحل»** باسم مرحلته تحت اسمه، **ولا يظهر** في تبويب «المعلمون».
- [ ] احفظ بلا اختيار أي مرحلة ← يُرفض برسالة «اختر مرحلة واحدة على الأقل».

### ما يراه
- [ ] سجّل الدخول بحسابه ← الدور تحت اسمه **«مدير مرحلة»**.
- [ ] الرئيسية: العدّاد مكتوب عليه **«طلاب مرحلتي»**، والحلقات النشطة = حلقات مرحلته فقط.
- [ ] «الحلقات» ← عنوانها «حلقات مرحلتي» وتعرض حلقات مرحلته فقط، **بلا** زر إضافة ولا تعطيل ولا جدول (قراءة فقط).
- [ ] «طلاب مرحلتي» ← لا يظهر فيها أي طالب من مرحلة أخرى ولا طالب بلا حلقة.

### ما يفعله
- [ ] أضِف طالباً إلى حلقة من مرحلته ← ينجح.
- [ ] حاول إضافة طالب **بلا حلقة** ← يُرفض (الطالب بلا حلقة لا ينتمي إلى مرحلة فلن يراه بعدها).
- [ ] افتح بطاقة طالب من مرحلته ← «تعديل» يفتح كل الحقول (لا بيانات المتابعة وحدها كالمعلّم).
- [ ] «نقل إلى حلقة أخرى» ← القائمة لا تعرض إلا حلقات مرحلته.
- [ ] «حضور المعلمين» ← يظهر **معلّمو حلقات مرحلته فقط** (لا السكرتير ولا اللجنة ولا معلّمو المراحل الأخرى) ← سجّل «حاضر» لأحدهم ← الملخص الشهري يعكسه.
- [ ] «الإحصاءات» ← جدول الطلاب يعرض طلاب مرحلته فقط.

### ما يُمنع منه
- [ ] لا تظهر له: الإعدادات، هوية المركز، سجل التعديلات، الكادر، أولياء الأمور، النسخة الاحتياطية.
- [ ] بطاقة الطالب **بلا زر «أرشفة»**.
- [ ] كمدير المركز: بدّل مراحله (أضِف مرحلة ثانية) ← **جلسته الحالية تنتهي** ويُطلب منه الدخول من جديد، وبعده يرى المرحلتين.
- [ ] كسكرتير: لا يظهر له تبويب «مديرو المراحل»، ولا يستطيع تعديل حساب مدير المرحلة.

## المرحلة 14ج — معلّم بأكثر من حلقة + مدير مرحلة يدرّس (10 دقائق)

> منشور (هجرة 0009، نسخة dc77878d).

- [ ] كمدير: أسنِد معلّماً واحداً إلى **حلقتين** (أساسي في كلٍّ منهما) ← يُقبل بلا رسالة «مرتبط بحلقة أخرى».
- [ ] الكادر ← بطاقة المعلّم تعرض **الحلقتين معاً** وهو **يظهر مرة واحدة** في القائمة.
- [ ] كالمعلّم: الرئيسية تقول «2 حلقات» وتسرد اسميهما.
- [ ] «التسميع» ← يظهر **مبدّل حلقة** بحلقتيه فقط؛ بدّل بينهما فتتغير قائمة الطلاب.
- [ ] «الكشف» ← نفس المبدّل، ويحمّل كشف الحلقة المختارة.
- [ ] «طلابي» ← تجمع طلاب الحلقتين معاً.
- [ ] معلّم لحلقة واحدة: **لا يظهر له مبدّل** (لا حاجة إليه).
- [ ] كمدير: عيّن **مدير المرحلة** معلّماً لحلقة في مرحلته ← يُقبل الآن.
- [ ] كمدير المرحلة: «التسميع» ← تُفتح لوحته على حلقته هو ويسجّل فيها تسميعاً.
- [ ] حضور المعلمين (كمدير المرحلة): **لا يظهر اسمه** في القائمة؛ وكمدير المركز: يظهر ويسجَّل حضوره.
- [ ] حضور الكادر: اختر «بعذر» ← تُطلب ملاحظة السبب ولا يُحفظ بدونها؛ نفس الشيء لـ«متأخر». «حاضر» و«غائب» يُحفظان مباشرة.

- [ ] **مقدمة الواتساب**: في كل نموذج (كادر، ولي أمر، جوال الطالب) القائمة فيها **970 و972 فقط**. في ملف الاستيراد: `+972` و`00972` تُقبل، و`962` يظهر الصف بملاحظة «مقدمة الواتساب المسموحة 970 أو 972 فقط».
- [ ] **إسناد حلقة لمدير المرحلة**: الحلقات ← إضافة/تعديل ← قائمة المعلّم الأساسي تضمّه بوسم «(مدير مرحلة)» ← يُحفظ.
- [ ] **حذف الكادر**: افتح معلّماً جديداً بلا حلقة ← «حذف الحساب» ← تأكيد ← يختفي ولا يدخل. جرّب معلّماً **على حلقة** ← يُرفض برسالة «انقله من الحلقة أولاً أو عطّل الحساب».

## المرحلة 14د — المراجعة بجانب الحفظ + Excel + الصور (15 دقيقة)

> ينتظر النشر (هجرة 0011).

- [ ] **التسميع اليومي** ← افتح طالباً: قسم «المراجعة (تُسجَّل أولاً)» ثم «الحفظ الجديد»، ولكل قسم مربع تفعيل وتقييم. فعّل المراجعة فقط بلا حفظ جديد ← يُحفظ.
- [ ] سجّل مراجعة من البقرة 1 إلى البقرة 20 ← افتح الطالب **في اليوم التالي**: بداية المراجعة **مقترحة من البقرة 21**، وتحتها «آخر مراجعة انتهت عند …»، ويمكنك تغييرها لأي موضع (لا تُلزَم بالناس أو البقرة).
- [ ] راجع بترتيب معاكس لاتجاه الطالب (طالب تنازلي يراجع من البقرة إلى آل عمران) ← يُقبل.
- [ ] «نهاية المراجعة قبل بدايتها» ← رسالة خطأ ويُعطَّل الحفظ. حضور بلا حفظ ولا مراجعة ← يُمنع.
- [ ] «غائب» أو «بعذر» ← تختفي أقسام المراجعة والحفظ ولا تُحفظ مراجعة.
- [ ] نموذج الطالب: لا يوجد حقل «المحفوظ (أجزاء)»؛ يوجد «خطة الحفظ الشهرية» و«خطة المراجعة الشهرية» و«موضع الحفظ الجديد».
- [ ] بطاقة الطالب وقائمة الطلاب: يظهر **موضع الحفظ وموضع المراجعة** ولا يظهر «N جزءاً» في أي شاشة (بطاقة الطالب، قائمة الطلاب، اختيار الطلاب للاختبار، الكشف، الشهادة).
- [ ] **الكشف الشهري**: بجانب شريط الحفظ شريط للمراجعة (صفحات/خطة/نسبة)، وزر «تصدير الكشف Excel» يُنزّل ملف `.xlsx` يفتح في Excel من اليمين لليسار.
- [ ] «تقارير» ← تقارير الطلاب وتقارير المعلمين: زر «تصدير Excel» فقط (لا PDF/طباعة).
- [ ] بطاقة الطالب ← تقرير/شهادة/بطاقة: زر «تصدير … كصورة» يُنزّل PNG (وعلى الجوال تظهر نافذة المشاركة إن أمكن). الصورة بخط عربي سليم.
- [ ] الاستيراد ← «تنزيل نموذج جاهز»: ملف Excel بالأعمدة المطلوبة.
